---

Run a post-interview debrief:

1. Ask: which company/stage, how did it feel, what questions came up.
2. For any question he struggled with, workshop a better answer now while it's
   fresh — offer to save it as a new `profile/accomplishments/` entry if it
   surfaced a story that wasn't captured yet.
3. Update `pipeline/<company-slug>.md`: stage, notes, next_action, next_action_date.
4. If a follow-up thank-you note is wanted, draft it — do not send anything
   without explicit go-ahead in chat.
5. Run `node scripts/build-dashboard.mjs` to refresh the dashboard.
